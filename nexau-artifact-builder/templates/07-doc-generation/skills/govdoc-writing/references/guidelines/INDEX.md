# guidelines/ 导航索引

本目录是**跨文种通用的规范层**：不管写通知还是写请示，格式、行文关系、措辞的口径都在这三份里。
文种专属的结构框架和 JSON 示例不在这儿，在同级的 templates/ 目录。

| 文件 | 内容 | 何时查阅 |
|------|------|---------|
| `format-standard.md` | GB/T 9704 格式标准：纸张与版面（A4、天头 37mm、版心 156×225mm）、各要素字体字号、正文标题层级与 JSON level 对应关系、版头/主体/版记三大部分、用印规则、页码 | 需要确认排版细节，或不确定某级标题该用什么字体、对应 `level` 填几时 |
| `writing-rules.md` | 行文关系与规则（上行/下行/平行、逐级行文、不越级）、语体风格、数字使用规范、标点符号规范、各文种正文结构逻辑、段落写作要点 | 拿不准该向谁行文、语气该多正式、数字用汉字还是阿拉伯数字时 |
| `common-phrases.md` | 按文种归类的开头用语、过渡衔接用语、要求督办用语、结尾用语、常见动词搭配、发文字号格式、标题拟制规范 | 正文骨架已定、要把话说得像公文时；拟标题和发文字号时 |

## 使用建议

- 三份都是**速查表型**文档，按需读整份即可（单份 100~150 行），不必反复读。
- 排版参数以 `format-standard.md` 为准；它与文种模板里的零散描述冲突时，以本目录为准。
- `common-phrases.md` 的套语是**候选项不是必填项**，照抄全套会让正文显得空洞，挑贴合事由的用。
