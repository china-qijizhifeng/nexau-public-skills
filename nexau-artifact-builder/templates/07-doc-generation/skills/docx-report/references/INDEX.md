# docx-report / references 导航索引

本目录存放渲染 Word 红头文件时所依据的**法规与格式标准原文（要点整理版）**。
它们不是运行时必读项——只有当你需要核对某个排版参数、判断文种是否用对、或向用户解释"为什么这里必须这么排"时，才用 `read_file` 按需读取。
日常构造 JSON 请优先看上一级技能说明里的 section 字段对照表与 template-index，不要整篇加载本目录文件。

## 文件清单

| 文件 | 内容 | 何时查阅 |
|------|------|---------|
| `GB-T-9704-2012-党政机关公文格式.md` | GB/T 9704-2012《党政机关公文格式》要点：纸张与幅面（A4、天头 37mm 等）、印制装订要求、版头/主体/版记各要素的编排规则、公文特定格式 | 需要核对字号字体、页边距、发文机关标志位置、页码或版记排法等**排版细节**时 |

## 两份文件的分工

- 「**这份文件长什么样**」→ 查 `GB-T-9704-2012-党政机关公文格式.md`（格式标准，管排版）
- 「**这件事该发什么文**」→ 查 `中办发〔2012〕14号-党政机关公文处理工作条例.md`（工作条例，管文种与行文）

两者口径冲突时，以格式标准处理排版、以工作条例处理文种与行文关系，不要互相套用。
