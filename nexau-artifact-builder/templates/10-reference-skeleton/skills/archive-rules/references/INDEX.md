# archive-rules / references 索引

本目录存放 `archive-rules` 的大块原始规则资料；上一层的 skill 入口文件只做概览，**判定门类、定保管期限、起文件名时以本目录的文件为准**。

> ⚠️ 这里的门类码、保管期限、命名格式**全是占位示例**，上线前必须替换成你单位的真实归档规范。

## 文件清单

| 文件 | 内容 | 什么时候读 |
|---|---|---|
| `classification.md` | 档案分类体系：各门类（文书 WS / 财务 CW / 业务 YW / 照片影像 ZP）的涵盖范围、门类码、保管期限，以及一材料跨多门类时的归类原则与「期限就高不就低」规则 | 判定某份材料属于哪个门类、该保管多久时 |
| `naming.md` | 归档命名规范与目录结构：`<年度>-<门类码>-<流水号>-<主题简述>.<原扩展名>` 各字段取值规则、归档根目录的层级、重名冲突处理 | 重命名文件、建归档目录、遇到同名冲突时 |

本目录当前没有子目录；新增大块资料时优先在本目录平铺加文件，并在上表补一行。

## 读法

1. 先读 `classification.md` 定门类与保管期限 —— 门类码是 `naming.md` 里文件名的必填字段，顺序不能反。
2. 再读 `naming.md` 生成规范文件名与目标路径。
3. 两份文件都覆盖不到的情况：标 ⚠️ 转人工复核，不要自行外推规则。
